# Third-party data, provenance and public repository review

This deliverable is supplied to the author for research review. Possessing public files does NOT automatically establish a license to re-host all raw data in a public Zenodo record.

| Source | Supplied content | Status before public upload |
|---|---|---|
| Global Wind Atlas / DTU and World Bank | Five user-extracted modeled 100-m means, grid neighbourhood audit and provenance; national GeoTIFF NOT included | Preserve the source citation, attribution requirements and terms of the downloaded raster. Values are modelled geographic means, not measured wind. |
| ERA5 / Copernicus Climate Change Service (via Open-Meteo) | 2010–2025 hourly derived weather and ridge input archives | Check attribution and applicable Copernicus/Open-Meteo conditions; include accurate access date, method and any redistribution notices. |
| Statistics Canada 25-10-0015-01 | Monthly BC provincial reported wind production, 2016 onward | Open Government Licence — Canada and Statistics Canada source citation may permit reuse with proper attribution; confirm the exact table's current licence. Preserve the unusual 2020 records in unaltered source extracts. |
| Alberta Electric System Operator (AESO) | Historical reported hourly asset data; does not guarantee settlement-grade meter data | Licensing/redistribution permissions need independent review. **Do not upload raw AESO files publicly until conditions are confirmed.** Code and public source link can be supplied in the meantime. |
| Canada Energy Regulator | BC wind-capacity figure around 702 MW | Snapshot only. Do NOT treat a current installed figure as historical annual nameplate capacity without time-series support. |
| Project/operator sources about Wonder Valley | Public development information | The equal-load gas system is modeled, not a published operating plant configuration. Cite public project descriptions accurately. |

A source-retaining private-review archive and a public-deposit candidate are distinct. The latter should exclude unlicensed raw AESO files and any other datasets requiring permission, and explain the data-retrieval procedure. Do not invent a DOI or assert a completed Zenodo deposit.

Before depositing, verify scripts, files, input rights, README, license text for author-created code, and checksums; then create a Zenodo record and place the verified DOI/URL in the manuscript's Data and code availability statement.
